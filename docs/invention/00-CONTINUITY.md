## Mechanism-reading rules

- Laplace is not conventional gradient-trained GPU inference. Derive claims from its
  actual identity, evidence, physicality, fold, and operation mechanisms.
- Content identity is resolved through canonical substrate operations; do not mint ids.
- Unicode is the text floor; packaging and tokenizers do not redefine identity.
- Geometry proposes locality; typed evidence and consensus establish supported relations.
- Ordered facts live in trajectories and realized curves.
- Conventional checkpoints are witnessed model sources, not opaque runtime authorities.
- Layer/head ordinal is a comparison coordinate, not cross-model functional identity.
- Pooled model consensus precedes one answer path; it is not checkpoint arithmetic,
  runtime voting, or post-hoc judging.
- Recipes are content-addressed constructions. Export codecs do not define architecture.
- Heavy computation belongs in native code; managed/SQL layers orchestrate.
- Discover the installed operation surface before adding another implementation.

If an active requirement exists only in historical notes, restate and verify it in a
current specification or GitHub issue before implementation.
