MOLD-A-MODEL SYNTHESIS MAP
==========================

Purpose
-------

This specification maps conventional target-model slots to substrate-native evidence and operators. It is a consumer/export semantic map, not the native Laplace cognition ontology, not a requirement to reproduce a source checkpoint's topology, and not a product-tier model definition.

Authority law
-------------

A target construction may only consume source/context/evidence state within the principal's effective content/capability scope, including EXPORT when a consumer artifact leaves the current boundary.

A narrow exported model is a deliberately finite consumer artifact. It does not redefine the live Laplace world as less knowledgeable and must not be used as the cheap-tier execution path.

Construction law
----------------

1. Resolve effective principal authority plus explicit target/export scope.
2. Resolve canonical content and eligible recorded/calculated witnesses from that scope.
3. Apply the declared export recipe/operator mapping; do not substitute this target construction sequence for the native forward-pass COUPLE/ORIENT/ROUTE program.
4. Build bounded candidate circuits/operators from factors and trajectories.
5. Fold corroboration/conflict while retaining source provenance.
6. Materialize the declared layer/head/expert/operator schedule.
7. Emit deterministic artifacts plus cell-to-tensor receipts.

Layer and head counts are recipe outputs. A source's `L5.H7` remains source-scoped; it
may correlate with another source's `L9.H3` or with no circuit at all. Equal ordinals do
not establish equivalence.

Round-table law
---------------

Each model source contributes testimony to the same canonical entity/relation space.
The pooled construction is one consensus program, not a merge of compatible tensors,
concatenated vocabularies, runtime experts selected from original models, or N generated
answers followed by a judge.

Export law & native source attribution (royalty receipt)
--------------------------------------------------------

Every output slot declares its recipe, source scope, substrate cells, calculations, and
determinism inputs. Architecture-specific codecs translate the constructed program into
SafeTensors, GGUF, or another target. Codec limitations must fail explicitly; they may
not silently reshape the invention into a supported template.

All Mold-A-Model synthesis, scoped consensus refolding (`consensus.scoped_consensus(p_source_ids)`),
and source attribution must execute in the canonical SQL + native C layer (`liblaplace_synthesis`,
`liblaplace_core`, `laplace_substrate` / `Laplace-postgres`), never in duplicate C# CLI loops or
out-of-process `dotnet run` shells.

Every Mold-A-Model synthesis produces a deterministic **Source Attribution Receipt** computed in
native C + SQL over the touched consensus cells and containment DAG (`walk_up` / `attested`):

```text
source_id (witness trunk) | claims_touched | games | fisher_weight | share_bp (0..10000)
```

where `share_bp` sums to exactly `10000` (100.00%) across all contributing witness trunks in
`p_source_ids`, weighted by each witness's Glicko-2 Fisher information ($I_{c,s} = g(\varphi_s)^2 E(1 - E)$ / $1/\varphi^2$)
on the exported cells. This receipt both audits the model's provenance and settles royalty splits
to licensed Knowledge Seeders.

Acceptance
----------

- Every materialized slot has a provenance receipt and a basis-point source attribution receipt (`share_bp` summing to `10000`).
- Synthesis and attribution execute in native C + SQL (`liblaplace_synthesis` / `laplace_substrate` / `Laplace-postgres`) with zero hand-rolled C# BPE/eigenmap/SVD or inline SQL wheels.
- Source-only and pooled recipes are reproducible.
- Incompatible architectures can contribute without ordinal or dimension equality.
- Held-out behavior distinguishes meaningful scoped constructions.
- External load/generation validates the codec, not merely file syntax.
