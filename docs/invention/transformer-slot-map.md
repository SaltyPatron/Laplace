Conventional slot names are codec and comparison vocabulary. Laplace's native model is
the typed operation program and witnessed substrate state.

Knowledge authority and compute envelopes remain outside consumer tensor slots: a target export may select an authorized source/scope for a declared artifact, but commercial tiers do not redefine the live substrate as smaller knowledge models.

## Governing laws

- Exact content identity precedes projection.
- Trajectory order is never replaced by point proximity.
- Geometry proposes candidates; typed evidence governs selection.
- Each source's circuit slices remain source-scoped.
- Cross-model equivalence is calculated functional evidence, not shared ordinal identity.
- Pooled consensus produces one answer path before export/inference.
- Every codec slot traces back to substrate cells and recipe calculations.

The full construction mapping is normative in spec 12; the forward execution order is
normative in specs 36 and 37.
