MOLD-A-MODEL SYNTHESIS MAP
==========================

Purpose
-------

This specification maps conventional model slots to substrate-native evidence and
operators. It is a semantic map, not a requirement to reproduce a source checkpoint's
topology or copy its weights.

Slot map
--------

Conventional surface         Substrate-native construction
---------------------------  ---------------------------------------------------------
Vocabulary / tokenizer       Unicode floor, canonical entities, modality trajectories
Token embedding              content identity, S³ placement, source-scoped projections
Positional encoding          trajectory ordinal, curve continuity, Hilbert locality
Attention Q/K/V/O            typed circuit factors, pair evidence, routed relations
Attention heads              source circuits grouped/aligned by witnessed function
MLP / experts                factor trajectories, gated typed transformations
Router / gate                relation bands, task orientation, evidence-conditioned route
Residual stream              typed strata carried through the active frontier
Normalization                deterministic scale policy derived by recipe/evidence
Logit / output head          typed completion candidates and conservative consensus score
KV / runtime cache           session/frontier state with deterministic invalidation
Layers                       ordered operation schedule, not mandatory source ordinals
Loss / optimizer history     witnessed outcomes and standing uncertainty-bearing fold

Construction law
----------------

1. Resolve canonical content and declared source scope.
2. Select eligible recorded and calculated witnesses.
3. Route evidence by relation type, band, tier, modality, and task.
4. Build bounded candidate circuits/operators from factors and trajectories.
5. Fold corroboration/conflict while retaining source provenance.
6. Materialize the declared layer/head/expert/operator schedule.
7. Emit deterministic artifacts plus cell-to-tensor receipts.

Layer and head counts are recipe outputs. A source's `L5.H7` remains source-scoped; it
may correlate with another source's `L9.H3` or with no circuit at all. Equal ordinals do
not establish equivalence.

Round-table law
---------------

Each model source contributes testimony to the same canonical entity/relation space.
The pooled construction is one consensus program, not a merge of compatible tensors,
concatenated vocabularies, runtime experts selected from original models, or N generated
answers followed by a judge.

Export law
----------

Every output slot declares its recipe, source scope, substrate cells, calculations, and
determinism inputs. Architecture-specific codecs translate the constructed program into
SafeTensors, GGUF, or another target. Codec limitations must fail explicitly; they may
not silently reshape the invention into a supported template.

Acceptance
----------

- Every materialized slot has a provenance receipt.
- Source-only and pooled recipes are reproducible.
- Incompatible architectures can contribute without ordinal or dimension equality.
- Held-out behavior distinguishes meaningful scoped constructions.
- External load/generation validates the codec, not merely file syntax.
