# Mechanism notes

These notes state how particular parts of the machine operate. They do not order the work and they do not replace `docs/INVENTION.md`.

- [`INGEST_BOUNDARY_AND_RECIPE_LAW.md`](INGEST_BOUNDARY_AND_RECIPE_LAW.md) — artifact, transport, parser, tier, and canonical admission are different boundaries. One recipe admits them.
- [`DATASET_ESTATE_MODERNIZATION.md`](DATASET_ESTATE_MODERNIZATION.md) and [`DATASET_ESTATE_REFRESH_OPERATOR.md`](DATASET_ESTATE_REFRESH_OPERATOR.md) — the selected source estate and how a staged release is acquired.
- [`REAL_CONVERSATION_AND_MODEL_CONSENSUS_FINISH_LINE.md`](REAL_CONVERSATION_AND_MODEL_CONSENSUS_FINISH_LINE.md) — a turn is an ordered witnessed trajectory on the forward program. Other models are witnesses.
- [`MODEL_INGESTION_DESIGN.md`](MODEL_INGESTION_DESIGN.md) — a checkpoint is a source. Weights are transient operands.
- [`physicality-descriptor-admission.md`](physicality-descriptor-admission.md) — a physicality descriptor is admitted structure, not a private store.
- [`EXPLORE_DISPLAY_LABEL_CONTRACT.md`](EXPLORE_DISPLAY_LABEL_CONTRACT.md) — a label is a realization. It is not the entity.
- [`CI_CD_OPERATOR_MODEL.md`](CI_CD_OPERATOR_MODEL.md) — delivery installs one revision of the surfaces whose bytes changed.
- [`WORKSTREAMS.md`](WORKSTREAMS.md) — names for areas of the same machine.
- [`CHESS_QUALIFIED_FLOOR_EXPORT.md`](CHESS_QUALIFIED_FLOOR_EXPORT.md) and [`CHESS_RECORDED_FLOOR_SERVING_ACCEPTANCE.md`](CHESS_RECORDED_FLOOR_SERVING_ACCEPTANCE.md) — chess positions and moves are identities and trajectories on the common substrate.
