# Historical scratchpad archive

Every file in this directory is a frozen session, audit, campaign, ledger, or research
record. No file here is current status, active instruction, or the definition of work.

Rules:

- Do not select tasks from this directory.
- Do not update issue state or implementation status here.
- Do not treat unchecked boxes, “open” labels, counts, or recommendations as current.
- Active requirements must be restated in a normative spec or GitHub issue.
- Verify any cited claim against current code or the running system.
- Preserve these files as historical evidence; do not append new session logs here.

Active status belongs only in GitHub. The authority hierarchy is
[`docs/DOCUMENTATION_GOVERNANCE.md`](../docs/DOCUMENTATION_GOVERNANCE.md).
