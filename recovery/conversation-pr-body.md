Native conversation execution currently loses prompt structure and performs expensive graph reductions through SQL. Ingestion also drops source resident-memory estimates and admits an entire compose batch before measuring retained native allocations.

This change adds exact prompt-tree resolution, direct native consensus scans with bounded neighbor retention, and ordinal-preserving continuation matching. It packages execution functions in a versioned module and verifies SQL bindings against the library that owns each symbol. Shared ingestion retains complete source profiles, accounts for native grammar allocations and source payloads, and drains compose groups as their measured memory fills the working-set envelope.

Validation belongs to the required PR CI workflow. Coverage includes native neighbor/continuation regressions, profile propagation, and composing actual repository C files through the native grammar implementation and PostgreSQL writer. Full coherent conversation, learning, model ingestion/export, chronological consensus, and the requested production throughput remain acceptance obligations; these component checks do not establish full product delivery.
